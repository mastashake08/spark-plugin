spark-mls-client examples

Same ListingGrid/ListingCard components, same data, three different frameworks.

Each page uses SparkProxyClient, not SparkClient — it calls VITE_SPARK_API_BASE_URL (your own backend, e.g. a running spark-api-micro instance), never Spark directly. Spark's API forbids sending the access token to a browser and has no CORS support anyway; that backend holds the token server-side and returns plain JSON.
